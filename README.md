# Paradise Nursery Shopping Application

Paradise Nursery is a responsive e-commerce web application built with React and Redux Toolkit. It allows users to explore a wide variety of houseplants categorized by type, view detailed plant information, manage a shopping cart, and dynamically calculate costs.

## Features
- **Landing Page**: Immersive background image with a welcoming company introduction and a "Get Started" call-to-action button.
- **Product Catalog**: Displays unique houseplants grouped across at least three distinct categories with thumbnail images, descriptions, and pricing.
- **Interactive Shopping Cart**: Add plants to the cart, adjust quantities, remove items, and see real-time updates for total costs and cart item counts.
- **Navigation Bar**: Persistent header across views linking to Home, Plants, and Cart with a dynamic cart counter.

## Tech Stack
- React (Functional Components, Hooks)
- Redux Toolkit (State Management)
- CSS3 for Styling
